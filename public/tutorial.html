🏫 Classrooms

A classroom represents one exam. Each classroom has a unique code that students use to join.

Create a Classroom

Go to Classrooms in the sidebar and click Add Classroom. Fill in the classroom name (e.g., "Mathematics Final Exam 2026").

Configure Exam Settings

Set the number of questions per exam, timer duration (in minutes), and choose whether to show results immediately, reveal correct answers, or allow answer review.

Tip: Leave the timer empty for untimed exams. Students can submit whenever they're ready.

Add Instructions

Write custom instructions that students will see before starting the exam. This is a good place for rules, allowed materials, etc.

Assign Questions

Open the classroom details and go to the Questions tab. Click Add Questions to select questions from your question bank. You can filter by category and difficulty level.

Important: Make sure you assign at least as many questions as the "questions per exam" setting. If you set 10 questions per exam, assign at least 10 questions.

Share the Code

Each classroom gets a unique 6-character code (e.g., ABC123). Share this code with your students. They enter it on the homepage to start the exam.

Activate / Deactivate

Toggle the classroom's active status. When deactivated, students cannot access the exam with the code. Use this to control when exams are available.

🔀 Shuffle Questions

Enable this to randomize the question order for each student, reducing cheating.

👁️ Preview Exam

Click Preview Exam in classroom details to see exactly what students will see.

❓ Question Bank

Create and manage your questions. Questions can be reused across multiple classrooms.

Add a Question

Click Add Question. Select a category, type the question text, fill in 4 answer options (A-D), and select the correct answer.

Set Difficulty Level

Click the stars (1-5) to set the difficulty. This helps other teachers filter questions by level when building exams.

StarsLevelUse for
1Very EasyBasic recall questions
2EasySimple understanding
3MediumApplication questions
4HardAnalysis and evaluation
5Very HardComplex problem solving

Add an Image (Optional)

Upload an image for questions that need diagrams, charts, or photos. Max file size: 2MB.

Shuffle Answers

Enable Shuffle Answers to randomize the order of options A-D for each student. The ABCD labels will be hidden.

Bulk Import / Export

📤 Import CSV

Upload a CSV file to add many questions at once. Click Import CSV and upload your file. Categories are auto-created if they don't exist.

📥 Export CSV

Click Export CSV to download all questions. Use this for backup or to transfer questions to another ExamJe installation.

CSV format: question_text, option_a, option_b, option_c, option_d, correct_answer, difficulty, category, shuffle_answers. Download the template from the import modal for a ready-to-fill example.

📁 Categories

Organize your questions into categories for easy filtering and management.

Create Categories

Go to Categories and click Add Category. Give it a name (e.g., "Algebra", "Biology Chapter 5") and optional description.

Use Categories to Filter

In the Question Bank, use the Category dropdown to quickly find questions from a specific topic.

Note: You cannot delete a category that has questions assigned to it. Move or delete the questions first.

🎓 Students

Students register themselves when they enter the exam code. You can also pre-add students.

Automatic Registration

Students self-register by entering the exam code on the homepage. They fill in their name, matric number, email, and phone number.

Student Groups

Create groups within a classroom (e.g., "Section A", "Section B"). Students select their group during registration. Use this to organize and filter results.

View Students

Go to Students to see all registered students. Search by name, email, or matric number.

📝 Exam Day

Here's what happens when students take the exam.

Students Enter the Code

Students visit your ExamJe site, enter the classroom code, and register with their details.

Review Instructions

Students see the exam instructions you wrote, along with the question count and time limit. They click Start Exam when ready.

Answer Questions

Students navigate through questions, select answers, and can skip and return to any question. A progress bar shows how many they've answered.

Timer and Auto-Submit

If a timer is set, students see a countdown. They get a yellow warning at 5 minutes and a red warning at 1 minute. When time runs out, the exam auto-submits.

Submit and View Results

After submitting, students see their score with a visual gauge, pass/fail status, and (if enabled) a review of their answers showing correct/wrong.

🔒 Anti-Cheat

Copy, paste, right-click, and keyboard shortcuts (Ctrl+C, F12, etc.) are disabled during the exam.

🔄 Re-check Results

Students can revisit their results anytime by entering their matric number and email for verification.

📢 Announcements

Send real-time scrolling messages to students during an ongoing exam.

Go to Announcements

Click Announcements in the sidebar. Select the exam room you want to send a message to.

Type Your Message

Write a short message (up to 500 characters). For example: "10 minutes remaining. Please check your answers." or "Question 5 has been updated."

Set Duration and Repeat

Choose how long the message stays active (1-60 minutes). Set a repeat interval if you want the message to scroll, disappear, and reappear periodically.

SettingWhat happens
No repeatMessage scrolls continuously until it expires
Every 30 secondsMessage scrolls once, hides, reappears after 30s
Every 5 minutesMessage appears briefly every 5 minutes

Send

Click Send. The message appears as a scrolling blue banner at the top of all students' screens within 5 seconds. It does not block their questions.

Tip: You can stop an announcement early by clicking the stop button in the announcement history table.

📈 Results & Analytics

Track student performance and exam statistics.

View Exam Results

Go to Exam Results to see all completed exam sessions. View each student's score, completion time, and individual answers.

Analytics Dashboard

The Analytics page shows overall statistics: total exams taken, completion rate, average score, and pass rate (50% threshold). A performance breakdown by classroom is also available.

Notifications

Click the bell icon in the top bar to see recent exam completions. New completions show a red badge. Click Mark all read to clear.

⚙️ Settings

Configure system settings and manage your account.

🖼️ System Logo

Upload your own logo from Settings. It replaces the default logo on all pages. Accepts PNG, JPG, SVG, WebP (max 2MB). Click "Reset to Default" to revert.

🔑 Change Password

Enter your current password and set a new one (minimum 8 characters). You'll stay logged in after changing.

👥 Admin Users

Go to Admin Users to add more administrators. Each admin has full access to all features. You cannot delete your own account.

📋 Activity Logs

The Activity Logs page shows all system actions (logins, logouts, changes) with timestamps and IP addresses for audit purposes.
